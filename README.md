# hci-project
## Getting Started

This repository requires **Python 3.8 to 3.11** due to framework dependencies.

### For Mac Users:
1. Open terminal in the directory and initialize setup:
   ```bash
   ./setup.sh
   ```
2. Activate and run:
   ```bash
   source mp_env/bin/activate
   pip install -r requirements.txt
   python main.py
   ```

### For Windows Users:
1. Open Command Prompt (cmd) in the directory and initialize setup:
   ```cmd
   setup.bat
   ```
2. Activate and run:
   ```cmd
   mp_env\Scripts\activate.bat
   pip install -r requirements.txt
   python main.py
   ```
